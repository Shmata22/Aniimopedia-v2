# Aniimopédia V2

Tous les fichiers sont à la racine pour GitHub Pages mobile :

- index.html
- styles.css
- app.js
- aniimo.json

Les images officielles sont chargées depuis les ressources CDN publiques du Wiki officiel Aniimo. Les données françaises et l'ordre du Pokédex proviennent du Wiki officiel.

La progression et les favoris sont sauvegardés en localStorage. Export/import permet le transfert entre appareils.

Pour ajouter un Aniimo : ajouter une entrée dans `aniimo.json`. Pour une image locale, remplacer le champ `image` par le nom du fichier ajouté à la racine.
